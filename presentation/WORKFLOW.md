# Путь от Excel до готовой презентации

Есть **два способа** собрать презентацию. Оба используют одни и те же данные, дизайн и диаграммы.

---

## Способ A. Офлайн-приложение `app.html` (рекомендуется, без кода)

Один самодостаточный файл: библиотека чтения Excel и пример уже встроены, интернет не нужен.

```
┌─────────────┐   ┌──────────────┐   ┌───────────────┐   ┌──────────────┐   ┌───────────┐
│ Открыть     │→ │ Загрузить    │→ │ Проверить/    │→ │ Живой         │→ │ Скачать   │
│ app.html    │   │ .xlsx (ФЭМ)  │   │ править       │   │ предпросмотр  │   │ PDF       │
│ (2× клик)   │   │              │   │ параметры     │   │ 4 слайда      │   │ (печать)  │
└─────────────┘   └──────────────┘   └───────────────┘   └──────────────┘   └───────────┘
```

**Шаги:**
1. **Открыть** `app.html` двойным кликом (любой браузер, офлайн). Сразу виден пример.
2. **📊 Загрузить Excel** — выбрать файл ФЭМ. Библиотека SheetJS парсит книгу прямо в браузере, читает ячейки по маппингу (см. ниже), пересчитывает тенге → USD по курсу и обновляет цифры и диаграммы.
3. **⚙ Параметры** — панель справа: курс ₸/$, название, локация, оффер (тело/ставка/срок — доход считается сам), гарантии, этапы (с датами для диаграммы Ганта). Правки применяются мгновенно.
4. **🖼 Фон** — при желании загрузить фото своего объекта.
5. **⬇ Скачать PDF** — открывает диалог печати. Выбрать «Сохранить как PDF», **включить «Фоновая графика»**, поля — «Нет». Получается векторный PDF: 1 слайд = 1 страница (16:9).

Файл собирается командой `python build_app.py` (нужен один раз; пересборка — только если меняете `app_template.html`).

## Способ B. Скрипт-генератор `generate.py` (для автоматизации)

Подходит, когда нужно генерировать пачками или из пайплайна.

```
femodel.xlsx ──┐
config.py    ──┤→  python generate.py  →  presentation.html  →  (Ctrl+P → PDF)
assets/*.jpg ──┘
```

1. Положить ФЭМ, указать имя в `config.py → EXCEL_FILE`.
2. Проверить маппинг ячеек `CELLS`, курс `USD_RATE`, заполнить `PROJECT`.
3. `python generate.py` → `presentation.html` (в консоли — извлечённые цифры для проверки).
4. Открыть в браузере, `Ctrl+P` → «Сохранить как PDF».

## Что и откуда берётся (общее для обоих способов)

| Данные | Источник |
|---|---|
| Выручка | `НДС расчет!C6` (Выручка с НДС) ÷ курс |
| Чистая прибыль | `Dashboard все!C4` (Net Profit) ÷ курс |
| Площадь к продаже | `Dashboard все!C25` |
| Цена за м² | выручка ÷ площадь |
| Структура площадей | `Dashboard все!L17/L18/L19` (офисы/коммерция/паркинг) |
| ROS, IRR | `Dashboard все!C5`, `C8` |
| Оффер, сроки, тексты, локация | вводятся вручную (нет в ФЭМ) |

Если структура ФЭМ у клиента другая — поправьте адреса ячеек: в приложении это объект `CELLS` в `app_template.html`, в скрипте — `CELLS` в `config.py`.

## Диаграммы

- **Пончик** «структура площадей» — слайд «Экономика»;
- **Стек-бары** «тело + доход» — слайд «Оффер»;
- **Гант** по этапам (из дат `start`/`end`) — слайд «Сроки».

Всё рисуется инлайн-SVG из данных. Палитра (`RAMP`) — контрастная и дальтоник-безопасная (проверена валидатором).
