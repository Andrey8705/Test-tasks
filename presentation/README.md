# Генератор инвестиционных презентаций

Собирает автономный HTML-тизер для строительной компании из финмодели (Excel) + метаданных проекта. Один HTML-файл: фон и диаграммы встроены (инлайн-SVG, без внешних библиотек), открывается в браузере, печатается в PDF, пересылается партнёрам.

**Дизайн:** тёмная тёплая тема, палитра «жжёная охра», диаграммы из данных ФЭМ:
- **пончик** «структура площадей» (офисы / коммерция / паркинг) — слайд «Экономика»;
- **стек-бары** «тело + доход» по каждой опции — слайд «Оффер»;
- **диаграмма Ганта** по этапам — слайд «Сроки».

Палитра диаграмм (`RAMP` в `generate.py`) проверена на цветовую доступность (CVD) и настраивается там же.

## Два способа собрать презентацию

- **Офлайн-приложение `app.html`** (без кода) — открыть двойным кликом, загрузить Excel, править параметры, скачать PDF. Подробно — в [WORKFLOW.md](WORKFLOW.md).
- **Скрипт `generate.py`** (для автоматизации) — правки в `config.py`, запуск, готовый `presentation.html`. См. ниже.

---

## Как сделать презентацию для нового клиента (скрипт)

1. **Положите новую финмодель** в эту папку и укажите её имя в `config.py` → `EXCEL_FILE`.
2. **Проверьте маппинг ячеек** в `config.py` → `CELLS`. Если структура ФЭМ другая — поправьте адрес листа/ячейки (в одном месте).
3. **Поставьте курс** `USD_RATE` (тенге за $1) на дату презентации.
4. **Заполните `PROJECT`** — название, локацию, оффер, сроки, фото объекта (`assets/`).
5. Запустите генератор:

   ```bash
   python generate.py
   ```

   На выходе — `presentation.html`. В консоли распечатаются извлечённые цифры (для проверки).

## Что откуда берётся

| Слайд | Данные | Источник |
|-------|--------|----------|
| 1. Титул | название, локация, формат | `config.py → PROJECT` (вручную) |
| 2. Экономика | выручка, площадь, прибыль, цена/м², ROS/IRR | **Excel** через `CELLS` (в USD по `USD_RATE`); цена/м² = выручка ÷ площадь |
| 2. Пончик | структура площадей (офисы/коммерция/паркинг) | **Excel** (`area_office/retail/parking` в `CELLS`) |
| 3. Оффер + бары | тело, ставка, срок | `config.py` (доход и итог считаются автоматически) |
| 4. Сроки + Гант | этапы RU/EN, даты `start`/`end` | `config.py` (даты в формате `ГГГГ-ММ` рисуют диаграмму Ганта) |

## Управление в презентации

- Стрелки / PageUp-Down / пробел — листать слайды
- Точки справа — переход к слайду
- `Ctrl+P` → «Сохранить как PDF» — экспорт (один слайд = одна страница, 1280×720)

## Файлы

- `config.py` — **единственный файл для правок** под клиента
- `generate.py` — логика чтения Excel и сборки HTML (менять не нужно)
- `assets/` — фоновые изображения
- `presentation.html` — результат (генерируется)
